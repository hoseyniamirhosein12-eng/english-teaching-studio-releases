# English Teaching Studio Pro

**English with ANDRI** — Windows desktop teaching workspace.

## Latest Stable release

[Open the latest Stable release and download the Windows installer](https://github.com/hoseyniamirhosein12-eng/english-teaching-studio-releases/releases/latest).


Stable releases are built from a matching, verified `vMAJOR.MINOR.PATCH` tag in the private source repository. The publishing workflow reruns regression checks before uploading the installer and updater metadata here.

The first installation is a one-time setup. After installation, the app checks GitHub Releases shortly after launch and every six hours. New Stable versions download in the background, then the app asks before installing and restarting. You do not need to uninstall the existing app or install a separate copy for each update.

## Updating safely

- Keep the existing English Teaching Studio installation in place.
- When an update is ready, choose **Install now** to apply it and restart, or **Later** to continue working.
- Student records, lesson edits, teacher notes, imported materials and settings are stored locally outside the installation folder.
- Export a backup from **Settings → Data & updates** before major changes as an additional precaution.

## Release assets

Each Stable release may include:

- **English-Teaching-Studio-Pro-x.y.z.exe** — Windows installer.
- **latest.yml** — metadata used by the in-app updater.
- **.blockmap** — update metadata used by the Windows updater.

## Source and privacy

This is the public distribution repository. Application source and private course-authoring material remain in the private source repository and are not published here.
